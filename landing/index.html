FAQ

Perguntas frequentes

Dúvidas comuns sobre a plataforma e a stack técnica.

O PlatformHub é gratuito para usar?
Sim. A plataforma foi desenvolvida como projeto acadêmico no curso DSM — FATEC e está disponível gratuitamente. O acesso ao painel completo é liberado após cadastro.
Qual stack técnica é utilizada?
Backend em Node.js com Express e TypeScript, banco de dados PostgreSQL via Sequelize ORM (Docker local ou Supabase em nuvem), frontend em React com React Router, e CI/CD automatizado com GitHub Actions.
Como funciona a autenticação JWT?
Ao fazer login, o servidor emite um access token (curto prazo) e um refresh token (longa duração). O frontend armazena os tokens de forma segura e o middleware Express valida o JWT em cada rota protegida. Ao expirar, o refresh token renova o acesso automaticamente.
Posso rodar o projeto localmente?
Sim. Com Docker instalado, basta clonar o repositório e executar docker-compose up --build na raiz do monorepo. O banco PostgreSQL e o servidor sobem automaticamente.
O CI/CD roda para qualquer mudança no repositório?
Não. Os workflows do GitHub Actions usam path filters para disparar apenas quando a pasta relevante é alterada — mudanças na landing/ ativam o deploy do Pages; mudanças no backend/ ativam o build da API.
